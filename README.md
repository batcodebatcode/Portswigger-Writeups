# PortSwigger Web Security Academy - Write-ups

Write-ups personnels des labs que je résous sur la [Web Security Academy](https://portswigger.net/web-security) de PortSwigger.

Chaque write-up documente le contexte du lab, la démarche suivie, la payload utilisée, ce que j'en retiens et la remédiation côté développeur. L'objectif est de garder une trace claire de ma progression et de montrer ma compréhension des vulnérabilités web, pas seulement leur exploitation.
